# 学生信息管理系统（PyQt5 + Fluent Design + MySQL）

基于 **PyQt5**、**[PyQt-Fluent-Widgets](https://github.com/zhiyiYo/PyQt-Fluent-Widgets)** 和 **MySQL** 实现的学生信息管理系统，数据库课程设计项目（2023 年）。

## 功能概览

系统分为 **学生 / 教师 / 管理员** 三种角色，登录后进入对应界面：

- **登录**
  - 学生、教师首次登录自动创建账户（初始账号密码均为学号/教师编号），之后可在设置中修改密码
  - 管理员账户由数据库初始化时手动创建
- **管理员**
  - 学生信息：按学号 / 生源地 / 年龄段 / 学分段 / 班级 / 专业 多维度查询，录入、删除学生
  - 基础数据：专业、班级信息录入
  - 成绩管理：按学生或按课程录入、修改、删除成绩（成绩变动自动结转已修学分）
  - 统计查询：按学年查询学生成绩、按专业统计平均学分成绩
  - 课表查询：按学生 / 班级 / 教师查看课表
- **学生**：查看个人信息、课表、已修课程学分与成绩（支持按学分 / 考试考查筛选、按学年统计）
- **教师**：查看个人信息、所授课表、按课程管理学生成绩
- **通用设置**：修改密码、明暗主题切换、登出返回登录界面

## 技术要点

- 界面使用 PyQt-Fluent-Widgets 的 Fluent Design 组件，自定义了标题栏、头像、消息条、表格代理等组件（`general/`）
- 数据访问统一封装在 `database.py`（PyMySQL），参数化查询防注入
- 复杂统计通过 MySQL 存储过程实现，成绩变动经触发器自动结转已修学分（`sql/01_schema.sql`）

## 运行方式

### 方式一：Docker 本地数据库（推荐）

数据库数据文件保存在项目内 `local_db/` 目录（已被 git 忽略），删除该目录即可彻底重置。

```bash
# 1. 启动 MySQL（首次启动自动建表并导入 sql/ 下的示例数据）
docker compose up -d

# 2. 配置连接信息（复制模板后按需修改，默认密码见 .env / docker-compose.yml）
cp config.example.ini config.ini

# 3. 创建虚拟环境、安装依赖并运行
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python main.py
```

### 方式二：使用已有的 MySQL（5.7+ / 8.0）

```bash
mysql -u root -p < sql/01_schema.sql
mysql -u root -p < sql/02_sample_data.sql   # 可选：导入示例数据
cp config.example.ini config.ini            # 填入你的 MySQL 账号密码
pip install -r requirements.txt
python main.py
```

连接信息也可以通过环境变量 `DB_HOST` / `DB_USER` / `DB_PASSWORD` / `DB_NAME` 配置。

### 测试账号（来自示例数据，均为虚构）

| 角色 | 账号 | 密码 |
|---|---|---|
| 管理员 | `admin` | `admin123` |
| 学生 | `202100000101`（或 102 / 201 结尾的另两个） | 首次登录 = 学号 |
| 教师 | `20210001` / `20210002` | 首次登录 = 教师编号 |

学生和教师的账户在**首次登录时自动创建**（账号、初始密码均为学号/教师编号），登录后可在“设置”中修改密码。账户数据保存在数据库的 `sms_suser` / `sms_tuser` / `sms_admin` 表中。

### 示例编号速查（测试各查询/录入界面时输入）

程序对编号有**纯数字 + 定长**校验，示例数据中的可用编号如下：

| 类型 | 位数 | 示例值 |
|---|---|---|
| 学号 Sno | 12 | `202100000101` ~ `202100000105`、`...0201`~`...0203`、`...0301`/`...0302` |
| 课程号 Lno | 12 | `100000000001` ~ `100000000007` |
| 班级号 Cno | 8 | `01012101` `01012102` `01022101` `01022102` `01032101` |
| 教师号 Tno | 8 | `20210001` ~ `20210005` |
| 专业号 Mno | 4 | `0101` `0102` `0103` |
| 学级/学年 | 4 | `2021`（学号前四位） |
